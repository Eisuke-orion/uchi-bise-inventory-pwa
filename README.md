# ウチの備瀬カフェ 在庫管理・発注アラートPWA

iPhoneのホーム画面から使える、バックエンド不要の在庫管理アプリです。商品・在庫・最終入力者はすべて端末の `localStorage` に保存されます。

## 公開URL

https://eisuke-orion.github.io/uchi-bise-inventory-pwa/

## 起動方法

```bash
npm install
npm run dev
```

表示されたURLをSafariまたはPCブラウザで開いてください。

## iPhoneのホーム画面に追加

1. HTTPSで公開したURLをiPhoneのSafariで開く
2. Safari下部の共有ボタンをタップ
3. 「ホーム画面に追加」→「追加」をタップ
4. ホーム画面の「備瀬 在庫」アイコンから起動

※ iPhoneからPCの開発用URLを開く場合は、同じWi-Fiに接続し、Viteに表示されるNetwork URLを使います。PWAの本番利用にはHTTPSでの公開が必要です。

## 使い方

- 「今日の在庫チェック」で入力者と各商品の数を入力し、「在庫を保存する」をタップします。
- 現在庫が下限以下の商品は自動で「発注」になります。
- 「発注リスト」から仕入れ先別の一覧を確認し、LINE共有用テキストをコピーできます。
- 「商品設定」で商品の追加・編集・削除、JSONの書き出し・読み込みができます。
- 初期商品マスタは店舗の在庫管理表に合わせた28品目です。
- 一度オンラインで開いた後は、主要画面をオフラインでも開けます。

## 確認・本番ビルド

```bash
npm run build
npm run preview
```

`dist/` の内容をHTTPS対応の静的ホスティングへ配置してください。
